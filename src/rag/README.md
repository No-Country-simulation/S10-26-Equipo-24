
# OpenBridge — RAG Generativo

## Objetivo
Generar recomendaciones de herramientas open source
y propuestas de arquitectura a partir de información
recuperada del catálogo de OpenBridge.

## Responsabilidades
- Recibir resultados de la búsqueda semántica.
- Incorporar las ideas de integración documentadas.
- Construir el contexto para el modelo generativo.
- Generar recomendaciones con referencias.
- Identificar integraciones pendientes de validación técnica.

## Integración
Entrada: resultados de recuperación semántica (Adrián).
Datos: catálogo e ideas de integración.
Salida: recomendaciones para la API de Backend (Ema).

## Estado
Prototipo desarrollado.
Pendiente de prueba completa con el modelo generativo
y de integración con los componentes del equipo.
